# Last Psyop scouting ledger

Purpose: a receipt-backed public-source map of the September 4–6, 2026 event, its publicly named organizers, cultural territories discussed by the organizers, and public signals of attendance.

Boundary:
- Public sources only.
- No private-data enrichment, doxxing, identity resolution from weak clues, or covert access to private communities.
- A public mention is not proof of registration or physical attendance.
- A Luma attendance count is not an exhaustive roster.
- “Enemy,” “operator,” “influencer,” and similar language remains attributed to the source unless independently established.
- Personal contact details are intentionally excluded from the working ledger.

Evidence states:
- observed: directly visible in a cited public source.
- attributed: a source claims it, but the ledger has not independently established it.
- hypothesis: an interpretation to test.
- unresolved: conflicting or insufficient public evidence.
- excluded: deliberately omitted because the claim would require private or unsafe inference.

Confidence:
- high: direct primary-source observation.
- medium: credible public secondary source or repeated public signal.
- low: weak, ambiguous, or uncorroborated signal.

The ledger is a starting point, not a completed attendee list. Search expansion should proceed through public event pages, public posts, organizer announcements, and public comments. Preserve the query, timestamp, result, and source URL for each search pass.
